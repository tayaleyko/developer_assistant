## Текст для вставки в диплом (по образцу Ozon)

Верификацию выполним на примере **облачного провайдера selectel.ru** — корпоративного B2B-сайта с каталогом IaaS/PaaS-услуг (серверы, Kubernetes, managed PostgreSQL, соответствие 152‑ФЗ).

При прохождении опроса были выставлены следующие настройки: **корпоративный сайт** (тип проекта), аудитория **в России**, команда **от шести разработчиков**, бюджет **свыше 1 млн руб.**, нагрузка **более 20 тыс. пользователей в сутки**, **критичные** требования к SEO, **SSR** и **React** на frontend, **расширенная авторизация**, **микросервисная** архитектура, **полнотекстовый поиск**, размещение в **российском облаке**, работа **24/7**, сфера **IT / технологии**, URL-ориентир `https://www.selectel.ru` (вопросы w4 и w_d4).

Как итог, система сформировала рекомендацию из стека **`nextjs_nestjs_pg`** за **0,07 с** (вероятность выбранного класса — **≈51 %**): **Next.js (React)** для клиентской части, **NestJS (Node.js)** для серверной, **PostgreSQL**, блок платежей и аналитики, рекомендации по дизайну для DevTools-сферы (sidebar, тёмная тема, технологичная палитра) — *рис. 4.X «Результат рекомендации для selectel.ru»*.

В режиме **«с AI»** (online) дополнительно выполнен разбор HTML: определены **Nuxt.js (Vue)** на frontend, **Ant Design**, шрифт **Manrope**, мегаменю (191 пункт), инфраструктура **Google Cloud** (CDN), палитра из **5 цветов** методом KMeans — *рис. 4.Y «Online-анализ selectel.ru»*.

Результаты сопоставлены с открытыми сведениями о продуктовой линейке Selectel и разметкой публичного сайта (табл. 4.5, продолжение — «Selectel»):

| Технология / признак | Факт (Selectel / парсер) | Рекомендация ИС (`nextjs_nestjs_pg`) |
|----------------------|--------------------------|--------------------------------------|
| Класс продукта | B2B, облако, high-load, 152‑ФЗ | Масштабируемый fullstack + БД ✓ |
| Frontend (сайт) | **Nuxt.js (Vue)** — по HTML | **Next.js (React)** ✗ |
| Backend (видимый) | Не определяется из HTML | **NestJS (Node.js)** |
| UI | **Ant Design** (парсер) | shadcn/Radix в дизайн-блоке |
| Managed БД в каталоге | PostgreSQL, MySQL, Redis | PostgreSQL в стеке ✓ (частично) |
| Альтернатива top-3 | — | **`vue_laravel_mysql`** (Vue + PHP) — ближе к Nuxt |

Предсказанная рекомендация ИС **соответствует классу** масштабируемого корпоративного web-портала с backend и СУБД, однако **не совпадает с frontend-стеком** публичного сайта (**Vue/Nuxt** вместо **React/Next.js**). Наиболее близкая альтернатива в top-3 — **`vue_laravel_mysql`**. Оценим соответствие как **«частичное»**: это отражает ограничение **фиксированного справочника меток** и эвристик парсера, а не ошибку заполнения опроса.
