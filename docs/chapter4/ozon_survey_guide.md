# Пошаговое заполнение опросника — профиль **ozon.ru**

Используйте для сценария **S_Ozon** (§ 4.2, табл. 4.4–4.5).

**Ожидаемый результат (offline):** метка `nextjs_nestjs_pg`, время ~0,04–0,07 с, полный отчёт.

---

## Перед началом

1. Запустите приложение: `app\main.py` (через `.venv\Scripts\python.exe app\main.py`).
2. На главном экране — **«Начать»**.
3. Тип проекта — **«Сайт»** (не «Десктопное приложение»).
4. Откройте блоки **по порядку 1 → 8**, в каждом ответьте на **все** вопросы → **«Сохранить блок»**.
5. После всех блоков (хотя бы одного полностью заполненного) — **«Далее»** → экран результатов.

> Вопросы, отмеченные **жирным**, влияют на предсказание MLP сильнее всего. Остальные нужны, чтобы кнопка «Сохранить блок» стала активной.

## Получение результата

1. Вернитесь на экран **«Выберите блок»** — у всех восьми блоков статус **«Завершён»**.
2. Нажмите **«Далее»** (справа внизу).
3. На экране результатов проверьте:
   - **Стек:** Next.js + NestJS + PostgreSQL;
   - **Метка:** `nextjs_nestjs_pg`;
   - **Top-3** и блок **дизайн**.

**Скриншот** этого экрана — для рисунка в § 4.2 (*«Результат рекомендации для профиля ozon.ru»*).
