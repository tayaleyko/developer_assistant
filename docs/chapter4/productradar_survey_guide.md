# Пошаговое заполнение опросника — профиль **productradar.ru** (online-анализ)

Используйте для сценария **S_ProductRadar** (§ 4.2): проверка **режима с AI** — парсинг реальной веб-страницы, технологии, дизайн, палитра KMeans.

**Эталон:** [Product Radar](https://productradar.ru) — нишевый российский каталог IT-стартапов и продуктов (аналог Product Hunt для РФ). Не относится к числу «мегабрендов» вроде Ozon или Habr, но стабильно отдаёт HTML и **успешно проходит** `site_analyzer`.

**Ожидаемый результат (online, нужен интернет):**
- блок **«Анализ указанного сайта»** без ошибки;
- **Backend:** PHP · **UI:** Tailwind CSS · **Аналитика:** Яндекс.Метрика;
- **Палитра (5 цветов):** `#e1d7c2`, `#f26124`, `#30a5bc`, `#9944de`, `#20233f`;
- время online-прогона ~**5–10 с** (загрузка страницы + KMeans).

**Offline (автономный):** метка `wordpress_php`, ~0,04 с — PHP-контур согласуется с результатом парсера.

---

## Перед началом

1. Запустите приложение: `.venv\Scripts\python.exe app\main.py`.
2. **«Начать»** → тип проекта **«Сайт»**.
3. Заполните блоки **1 → 8** → **«Сохранить блок»** в каждом.
4. **«Далее»** → экран результатов.
5. Переключите **«Режим с AI»** (не «Автономный режим») — начнётся загрузка и анализ URL из ответа **w4**.

> URL **обязательно** укажите в вопросе **w4** (блок 1). Для палитры можно продублировать в **w_d5** (блок 4) — иначе палитра строится с того же URL.

## Получение результата (режим с AI)

1. **«Далее»** → экран результатов (сначала показывается автономный отчёт).
2. Нажмите **«Режим с AI»** — появится «Анализ сайтов… Пожалуйста, подождите».
3. После загрузки проверьте секции:

| Секция | Что должно быть |
|--------|-----------------|
| Технологии (MLP) | стек по метке `wordpress_php` или близкий |
| Дизайн (MLP) | рекомендации для сферы tech |
| Похожие проекты | список аналогов для типа «лендинг» |
| **Анализ указанного сайта** | PHP, Tailwind CSS, Яндекс.Метрика, навигация ~51 пункт |
| **Палитра цветов** | 5 HEX + цветные swatches |

**Скриншот** экрана с блоками «Анализ указанного сайта» и «Палитра» — для § 4.2.
