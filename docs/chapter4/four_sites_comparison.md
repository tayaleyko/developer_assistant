## 1. Методика

Для каждого продукта:

1. Сформирован **профиль опроса** (тип сайта, масштаб, URL в **w4** / **w_d4**), соответствующий классу продукта.
2. Выполнен **offline-прогон** (`get_offline_result`) — MLP + справочник стека и дизайна.
3. Выполнен **online-прогон** (`get_online_result`) — парсинг HTML + KMeans-палитра.
4. Оценка полноты парсера (**analyzer_score**, max 7): фреймворк, backend, UI, навигация, шрифты, палитра ≥3, аналитика.

## 4. Глубинный разбор по сайтам

### 4.1. Selectel — облачный провайдер B2B

**Продукт:** IaaS/PaaS, серверы, Kubernetes, 152‑ФЗ, B2B ([selectel.ru](https://www.selectel.ru)).

**Профиль опроса:** corporate, tech, 6+ dev, 1M+ бюджет, 50–500k RPS, microservices, cloud_russia, React в опросе, URL в w4.

**Offline (MLP):**
- Метка **`nextjs_nestjs_pg`** (p≈**0,51**) — наивысшая уверенность среди четырёх.
- Top-3: `vue_laravel_mysql`, `nextjs_vercel` — намёк на Vue-контур (согласуется с парсером).
- Стек: Next.js + NestJS + PostgreSQL, облако РФ, ЮKassa/Stripe.
- Дизайн (сфера **tech**): технологичный стиль, sidebar, тёмная тема, shadcn/Radix.

**Online (парсер):**
| Поле | Значение |
|------|----------|
| Фреймворк | **Nuxt.js (Vue)** |
| Хостинг | **Google Cloud** |
| UI | **Ant Design** |
| Шрифты | Manrope, ui-sans-serif |
| Навигация | Мегаменю, **191 ссылка** |
| Палитра | `#eae5e1`, `#8892c5`, `#dc6531`, `#1c9faa`, `#17272e` |

**Сопоставление с реальностью:**
- **Частичное соответствие.** Маркетинговый сайт Selectel на **Vue/Nuxt** (парсер верен); опрос указал React → MLP дал **Next.js/React-метку**. По **классу** (масштабируемый B2B, облако, микросервисы, РФ) — релевантно; по **конкретному фреймворку** — расхождение, близкий альтернативный класс во top-3: `vue_laravel_mysql`.
- **Дизайн:** Ant Design и корпоративное мегаменю соответствуют B2B IT-порталу; палитра с бирюзово-синими акцентами близка к фирменному стилю провайдера.

**Вывод:** лучший **комплексный** кейс для § 4.2 — высокая p, богатый online-отчёт, без 403/429.

**Продукт:** онлайн-курсы, LMS, 1,5 млн пользователей ([netology.ru](https://www.netology.ru)).

**Профиль опроса:** saas, education, SPA, React, extended auth, microservices, cloud_russia.

**Offline (MLP):**

- Дизайн (сфера **education**): Nunito/Poppins, синий #2196F3 + оранжевый #FF9800, геймификация, прогресс-бар курса.

**Online (парсер):**
| Поле | Значение |
|------|----------|
| Фреймворк | **Next.js (React)** ✓ |
| Аналитика | **Google Analytics, Яндекс.Метрика** |

| Палитра | `#f89112`, `#50b8e1`, `#18c973`, `#09a8fd`, `#987585` |

**Сопоставление:**
- **Наивысшее совпадение offline ↔ HTML:** рекомендация Next.js **подтверждена** парсером.

- Offline-дизайн (education) **логичен** для EdTech; палитра с сайта (оранжево-голубая) **близка** к рекомендованной сине-оранжевой схеме.

## 5. Общие выводы (как для Ozon)

1. **Конвергенция метки.** При схожих «enterprise»-профилях все четыре сайта получили **`nextjs_nestjs_pg`** — MLP хорошо выделяет **класс масштабируемого web fullstack**, но **не различает** ниши (облако / EdTech / CMS / банк) без тонкой настройки опроса.

2. **Online vs offline.** Парсер дополняет отчёт **фактами из HTML** (фреймворк, аналитика, палитра); offline даёт **структурированный стек и дизайн по сфере**. Лучший эффект — при **совмещении** (режим «с AI»).

3. **Ограничения site_analyzer** (подтверждены на выборке):
   - SPA (Т‑Банк) — фреймворк часто «Не определён»;
   - CMS/конструктор (Tilda) — нет маркеров Next/Nuxt;
   - Backend **никогда** не определяется из HTML (by design).

4. **Выбор эталона для GUI и скриншота:**
   - **Selectel** — максимум данных в одном прогоне;
   - **Нетология** — если нужно показать **Next.js в блоке «Анализ сайта»**;
   - **Т‑Банк** — палитра и TinkoffSans для рисунка «финтех».
