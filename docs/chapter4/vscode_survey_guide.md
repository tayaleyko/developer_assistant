# Пошаговое заполнение опросника — профиль **Visual Studio Code**

Используйте для сценария **S_VSCode** (§ 4.2, табл. 4.4–4.5).

**Ожидаемый результат (offline):** метка `electron_js`, время ~0,04–0,07 с, полный отчёт (стек + дизайн).

**Эталон продукта:** Visual Studio Code — кроссплатформенный редактор кода; **языки** — TypeScript и JavaScript; **платформа** — Electron (Chromium + Node.js), веб-технологии в UI.

---

## Перед началом

1. Запустите приложение: `app\main.py` (через `.venv\Scripts\python.exe app\main.py`).
2. На главном экране — **«Начать»**.
3. Тип проекта — **«Десктопное приложение»** (не «Сайт»).
4. Откройте блоки **по порядку 1 → 8**, в каждом ответьте на **все** вопросы → **«Сохранить блок»**.
5. После всех блоков — **«Далее»** → экран результатов.

> Вопросы, отмеченные **жирным**, влияют на предсказание MLP сильнее всего. Остальные нужны, чтобы кнопка «Сохранить блок» стала активной.

## Сопоставление с реальным стеком VS Code

| Компонент | Visual Studio Code (факт) | Рекомендация ИС (`electron_js`) | Соответствие |
|-----------|-------------------------|----------------------------------|--------------|
| Платформа | **Electron** (Chromium + Node.js) | Electron | **Да** |
| Языки UI / логики | **TypeScript**, **JavaScript** | HTML/CSS/JS, Node.js main process | **Да** |
| Рендеринг | **Chromium** (Web) | Chromium (в составе Electron) | **Да** |
| Main process | **Node.js** | Node.js (main process) | **Да** |
| Локальное хранение | SQLite, файлы конфигурации | SQLite / IndexedDB | **Да** |
| Расширения | Extension API, marketplace | Не отдельная метка; близкий класс Electron | **Частично** *(архитектурный класс верен)* |
| Альтернатива в top-3 | — | `tauri_rust` (лёгкий Rust + Web) | Не выбран — VS Code сознательно на Electron |

**Вывод:** для профиля редактора кода на Electron система даёт **полное соответствие** по платформе и стеку; дизайн-рекомендации согласуются с IDE-интерфейсом VS Code (sidebar, tabs, тёмная тема, `#007ACC`).
