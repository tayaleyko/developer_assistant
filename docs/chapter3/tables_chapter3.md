## Таблица 3.4 — Гиперпараметры MLPClassifier (§3.3)

| Параметр | Значение | Назначение |
|----------|----------|------------|
| `hidden_layer_sizes` | (128, 64) | Два скрытых слоя |
| `activation` | ReLU | Нелинейность |
| `solver` | Adam | Адаптивный градиентный спуск |
| `learning_rate_init` | 0.001 | Начальный шаг обучения |
| `batch_size` | 32 | Размер мини-батча |
| `max_iter` | 300 | Верхняя граница эпох |
| `early_stopping` | True | Остановка при росте val loss |
| `validation_fraction` | 0.176 | Доля val из train (~15 % от всего) |
| `n_iter_no_change` | 20 | Patience |
| `alpha` | 0.001 | L2-регуляризация |
| `random_state` | 42 | Воспроизводимость |
| Разбиение выборки | test_size=0.15, stratify | Отложенный тест |

*Реализация: `train_model()` в `app/services/mlp_model.py`.*
