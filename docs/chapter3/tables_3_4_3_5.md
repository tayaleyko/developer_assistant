# Таблицы для пунктов 3.4 и 3.5

## Таблица 3.4.1 — Состав датасета для генерации UI-шаблонов

| Поле | Тип | Назначение |
|---|---|---|
| image_id | string | Идентификатор экрана |
| project_type | category | website / desktop |
| screen_type | category | home / catalog / dashboard / form |
| style_tag | category | minimalist / corporate / creative |
| palette | array(hex) | Цветовая схема |
| components | array | Типы элементов UI |
| layout_boxes | array(x,y,w,h,type) | Геометрия и иерархия элементов |
| metadata | json | Доп. признаки проекта |

## Таблица 3.4.2 — Рекомендуемые параметры обучения генеративной модели

| Параметр | Базовое значение | Комментарий |
|---|---|---|
| Разделение выборки | 70/15/15 | Train/Val/Test |
| Оптимизатор | Adam | Стабильный старт для cGAN |
| Learning rate | 0.0002 | Часто используется для GAN |
| Batch size | 32 | Компромисс скорость/память |
| Эпохи | 100-300 | До стабилизации метрик |
| Регуляризация | L2 / spectral norm | Снижение переобучения/нестабильности |
| Ранняя остановка | Да | По val loss / quality score |

## Таблица 3.4.3 — Критерии качества генерации шаблонов

| Критерий | Как измерять |
|---|---|
| Визуальная реалистичность | FID / экспертная оценка |
| Структурная корректность | Доля не пересекающихся блоков, валидность layout graph |
| Соответствие условиям | Совпадение с признаками из опроса |
| Пригодность к доработке | Экспорт в редактируемый формат (JSON/Figma/HTML) |
