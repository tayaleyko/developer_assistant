# Куда вставлять рисунки и таблицы (глава 3)

## Как получить картинки из PlantUML

1. Откройте https://www.plantuml.com/plantuml/uml/ или расширение PlantUML в VS Code / Cursor.
2. Откройте файл `.puml` из этой папки → Export PNG/SVG.
3. В Word: **Вставка → Рисунок**, подпись снизу: «Рисунок 3.X – …».

Нумерацию **3.X** продолжите после последнего рисунка главы 2.
